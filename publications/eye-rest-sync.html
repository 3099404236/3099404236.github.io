休息：Windows 与 HarmonyOS 同步离屏休息工具

3099404236 · 2026-08

摘要

本项目实现一个跨 Windows 与 Android/HarmonyOS 的强制离屏休息系统。Windows 客户端基于 Python、Tkinter 和 Win32 API，支持空闲感知计时、多显示器遮罩、托盘控制和紧急退出；Node.js 中继采用控制/只读令牌隔离并保留带版本号的休息状态；手机端使用原生 Java 前台服务和悬浮窗，通过 HTTPS 长轮询同步黑屏。公开版本包含 12 项自动测试、双显示器验证、HarmonyOS 4.2 实机验证，以及移除 USB 本地映射后的公网端到端测试。
