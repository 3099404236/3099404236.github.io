ChatGPT 网页到 Codex 的 Responses API 实验桥接器

3099404236 · 2026-08

摘要

这是一个面向本机实验的 Windows Agent 工作台。它接收 Codex 的 Responses API 请求，通过 Chrome DevTools MCP 或本机 Browser Relay 复用用户已经登录的 ChatGPT 标签页，再把网页回答转换为文本、函数调用或原生 apply_patch 事件。第二版新增跨重启会话 URL 映射、同页网关恢复、Thinking 中间态过滤、长文本分块、完成请求去重、对话确实失效后的结构化检查点交接、工作区任务面板、人工阶段门控和可选微任务委托。项目不绕过登录、验证码、用量限制或网站风控，也不声称等价于 OpenAI 官方 Responses API。
