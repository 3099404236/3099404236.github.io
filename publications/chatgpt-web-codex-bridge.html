ChatGPT 网页到 Codex 的 Responses API 实验桥接器

3099404236 · 2026-08

摘要

这是一个面向本机实验的 Windows Agent 工作台。它接收 Codex 的 Responses API 请求，通过 Chrome DevTools MCP 复用用户已经登录的 ChatGPT 标签页，再把网页回答转换为文本、函数调用或原生 apply_patch 事件。第三版把单页控制扩展为三条相互隔离的工作通道与一条持久旁白通道：工作通道使用会话亲和、租约代数和差异化空闲释放避免多个任务争抢同一标签页；旁白通道把已完成或失败的工作回合解释为可读进度，并在通道离线时本地排队、恢复后补放。启动器新增多次直连探测、健康 3+1 拓扑防降级，以及只匹配 Chrome 远程调试许可窗口的自动允许脚本。项目仍保留持久 URL、同页故障恢复、请求去重、长文本分块、结构化检查点和明确 Responses 终态；不绕过登录、验证码、用量限制或网站风控，也不声称等价于 OpenAI 官方 Responses API。
