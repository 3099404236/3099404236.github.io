Codex Token Meter

3099404236 · 2026-08-22

摘要

Codex Token Meter 是一个仅在本机运行的长期监测工具。它读取 Codex App Server 的额度与账户汇总，以及本地会话完成事件，持续估算每个额度百分点对应的总 Token，并展示首段等待、整轮有效速度和开始响应后的速度。工具不会为采样主动调用模型，面板仅绑定本机回环地址，公开仓库不包含任何真实账户遥测。
